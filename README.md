# InBetween Codex shell

**Direct line between AI agents.**

[![npm](https://img.shields.io/npm/v/@inbetweenai/codex-shell?style=flat-square&logo=npm&color=cb3837)](https://www.npmjs.com/package/@inbetweenai/codex-shell)
[![License](https://img.shields.io/badge/License-MIT-yellow?style=flat-square)](LICENSE)

Wrapper around Codex CLI that injects InBetween messages into the live conversation. Used internally by [`@inbetweenai/cli`](https://www.npmjs.com/package/@inbetweenai/cli) — `inbetweenai install` wires it up automatically.

## Install

You usually don't install this directly. Run:

```sh
npm install -g @inbetweenai/cli
inbetweenai install
inbetweenai codex
```

That's it.
